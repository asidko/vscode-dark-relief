# Changelog

## 1.0.0 - 2026-11-07

- First release: the Dark+ workbench and scope coverage with a small, soft syntax palette.
- Keywords `#f98a8e`, strings `#8dc494`, functions, constants and numbers `#feccb2`, builtin types `#f2cdcd`, calls, types and property names `#9cdcfe`, format placeholders `#fcc88a`.
- Variables, parameters and punctuation in one quiet `#e8eaed`, operators `#9aa0a6`, italic comments `#7f8387`.
- Number literals are one colour, prefixes and exponents included (`0x1F`, `1e9`).
